# 🐭 Discord Video Compressor (<20MB)

A simple, lightweight Windows app built to compress your video clips to **under 20 MB** so you can easily upload them to Discord without losing video quality.

 Features
* **Automatic Bitrate Scaling:** Uses a two-pass encoding system to automatically calculate the best bitrate based on your clip's length.
* **No Setup Required:** Comes as a single portable `.exe` file. Your friends don't need to install Python, FFmpeg, or any dependencies.
* **Clean UI:** Simple interface to select your file and monitor progress in real time.
* **Auto-Save:** Saves the compressed version directly in the same folder as the original file with `_discord.mp4` appended to the name.

 How to Use
1. Open **`Ratcompressor.exe`**.
2. Click **Select Clip** and pick any video file (`.mp4`, `.mov`, `.mkv`, `.avi`).
3. Wait a few seconds for the compression to finish.
4. Upload your new `<20MB` video directly to Discord!# discord-video-compressor
